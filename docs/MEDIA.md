# Media de catálogo

El esquema almacena únicamente `object_key`; nunca bytes. La configuración prevista usa `MINIO_ENDPOINT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_BUCKET_CATALOG` y `CATALOG_MAX_IMAGE_SIZE_MB`. La integración HTTP de carga queda pendiente de completar antes de habilitar media en producción.
