# Roadmap

- v0.1 Foundation: infraestructura, salud, esquema base y panel inicial.
- v0.2 Identity: tenants, usuarios, JWT, refresh tokens, roles y permisos.
- v0.3 Commerce: comercios, sucursales, horarios y catálogos.
- v0.4 Orders: carrito, pedidos, estados y trazabilidad.
- v0.5 Drivers: repartidores, disponibilidad y documentos.
- v0.6 Dispatch: asignación y ubicación en tiempo real.
- v1.0 MVP: operación inicial en una ciudad.
